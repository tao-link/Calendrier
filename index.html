⚙️ Installation à terminer

L’application n’est pas encore reliée à votre base de données Supabase. Rien n’est enregistré tant que ce n’est pas fait.

  1. Crée un projet gratuit sur supabase.com.
  2. Exécute le fichier supabase.sql dans l’éditeur SQL de Supabase.
  3. Dans index.html, section CONFIGURATION, remplace SUPABASE_URL et SUPABASE_KEY.
  4. Remets le fichier sur GitHub, puis recharge cette page.

Toutes les étapes sont détaillées dans le guide fourni avec l’application.
